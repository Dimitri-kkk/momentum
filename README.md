# Momentum Task Management App

A Jira-like task management application built with Next.js, React, and Tailwind CSS.

## Features

- View tasks organized by status columns (To Start, In Progress, Ready for Testing, Completed)
- Filter tasks by department, priority, and employee
- Responsive design for all screen sizes
- Persistent filters (saved in localStorage)
- Clean and modern UI

## Task Card Features

- Task title
- Truncated description (max 100 characters)
- Priority indicator
- Due date
- Department name
- Assignee avatar
